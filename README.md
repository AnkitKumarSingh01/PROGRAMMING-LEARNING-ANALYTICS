Programming Learning Analytics Dashboard is a Data Analytics and Visualization project that investigates the question:

“Does regular coding practice improve programming performance?”

The project analyzes programming-submission data to identify patterns between coding practice and programming performance. It measures factors such as total submissions, problems attempted, active practice days, practice span, and submissions per active day, and compares them with programming success rate.

The final outcome will be a professional interactive dashboard that presents the findings through charts, KPIs, statistical analysis, and meaningful insights, helping us understand how different patterns of coding practice are associated with programming performance.
